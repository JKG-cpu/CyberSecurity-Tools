# NetWatch

A command line tool that you can use to ping hosts, scan targets, sweep targets, and get banners + whois / dns data

## Installation

No installations implemented at the moment. If you would like to use this, just clone the repo.

## Usage

Run the --help command for help on commands
```bash
netwatchscn -- help   # INSTALLATION ONLY
```

Or if you have the repo locally
```bash
source .venv/bin/activate

python main.py --help
```

## Requirements

- Python 3.11+
