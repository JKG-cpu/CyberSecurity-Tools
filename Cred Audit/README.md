# Cred Audit

A command-tool that can crack hashes, hash strings, check a password's strength, and check if your password has been in and data breaches.

## Installation

No installations implemented at the moment. If you would like to use this, just clone the repo.

## Usage

```
cred-audit --crack <hash>
cred-audit --hash <str>
cred-audit --hibp <str>
cred-audit --strength <str>
```

If you need any more help, run
```
cred-audit -h
<or>
cred-audit -help
```

## Flags

| Flag | Description |
|------|-------------|
| `--details` | Get more details on a command you ran |
