================================================================
  CredAudit — Password Auditor & Credential Analyzer
  Project Idea
================================================================

OVERVIEW
--------
A modular password auditing toolkit that analyzes password
strength, cracks hashed passwords using wordlists, checks
credentials against known data breaches, and generates a
detailed report. Builds on ReconKit's multi-language pipeline
approach — Python for core logic, C# for report generation.


LANGUAGE SPLIT
--------------
  Python       →  Core auditing logic, API calls, CLI/UI
  C#           →  Report generator (same pattern as ReconKit)
  Config JSON  →  Settings (wordlist path, hash type, targets)


MODULES
-------
  1. hash_identifier.py
       - Detects the hash type from a given hash string
         (MD5, SHA1, SHA256, bcrypt, etc.)
       - Uses hash length + character patterns to identify

  2. wordlist_cracker.py
       - Takes a hash and a wordlist file
       - Hashes each word and compares to the target
       - Supports MD5, SHA1, SHA256
       - Returns the plaintext if found

  3. strength_scorer.py
       - Scores a plaintext password 0-100
       - Checks: length, uppercase, lowercase, numbers,
         symbols, common patterns (password123, qwerty, etc.)
       - Returns a grade: WEAK / FAIR / STRONG / VERY STRONG

  4. hibp_checker.py (HaveIBeenPwned)
       - Uses the HIBP k-anonymity API (no full password sent)
       - Checks if a password has appeared in a real breach
       - Returns how many times it was seen in breach data
       - API: https://api.pwnedpasswords.com/range/{prefix}

  5. ReportGenerator.cs (C#)
       - Reads results.json
       - Generates a color-coded HTML report
       - Shows: hash, cracked value, strength score, breach count
       - Same pattern as ReconKit's ReportGenerator

  6. main.py
       - Orchestrator, same argparse pattern as ReconKit
       - Args: --audit, --config, --report
       - Calls C# via subprocess for config validation + report

CONFIG FORMAT
-------------
  {
      "hash_type": "auto",         // auto, md5, sha1, sha256
      "wordlist_path": "wordlists/common.txt",
      "check_breaches": true,      // toggle HIBP API calls
      "output_folder": "output"
  }

ROADMAP
-------
  Week 1 — hash_identifier.py + wordlist_cracker.py
    - Identify hash types by length/pattern
    - Crack MD5/SHA1/SHA256 hashes against a wordlist
    - Write results to results.json

  Week 2 — strength_scorer.py + hibp_checker.py
    - Build the strength scoring system
    - Integrate the HIBP k-anonymity API
    - Learn about why k-anonymity keeps the password safe

  Week 3 — C# config validator + ReportGenerator
    - Reuse the same pattern from ReconKit
    - Add new fields to models for strength/breach data
    - Generate color-coded HTML report

  Week 4 — main.py + UI + polish
    - Wire everything together with argparse
    - Add rich terminal UI for inputting hashes/passwords
    - Commit to GitHub with a solid README


TOOLS & LIBRARIES
-----------------
  Python:
    hashlib        →  built-in, hashes strings (MD5/SHA/etc.)
    requests       →  HTTP calls to HIBP API
    rich           →  terminal UI (same as ReconKit)
    argparse       →  CLI args (same as ReconKit)

  C#:
    System.Text.Json    →  deserialize results.json
    System.Text         →  StringBuilder for HTML


WHAT YOU'LL LEARN
-----------------
  - How password hashing works (and why plain text storage is bad)
  - What a rainbow table attack is and how wordlists work
  - The k-anonymity model — how HIBP checks passwords privately
  - Why password length matters more than complexity
  - How real breach databases are used in security audits


IMPORTANT NOTE
--------------
  Only audit passwords you own or have explicit permission
  to test. Never use this tool on real user credentials
  without authorization. Use your own test hashes during
  development — generate them with Python's hashlib.

  Generate a test hash:
    import hashlib
    print(hashlib.md5("password".encode()).hexdigest())
    >>> 5f4dcc3b5aa765d61d8327deb882cf99
